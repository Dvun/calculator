# YieldPilot v2.2.1 — Trading Risk Planner

Trading-only React + Vite + TypeScript + Zustand. Бесплатный статический хостинг на Vercel или GitHub Pages. Данные каждого браузера остаются в `localStorage`; регистрация и серверная авторизация отсутствуют. Интерфейс без денежных обозначений.

## Обновление v2.2.1

- Новый автоматический расчёт первой ставки: **0,25–1% текущего депозита**, нижний предел реальной ставки — **1**. Доля плавно уменьшается, когда текущий депозит растёт относительно начального. При этом абсолютная ставка может расти.
- Первая ставка ограничивается максимальным убытком **всей серии**. Предел риска — **5% текущего депозита по умолчанию** (настраивается). Если минимальная серия из ставок `1, 2, 4, ...` не укладывается, показано `Недоступна`, а не придуманное разрешение на риск.
- По умолчанию: выплата **92%**, коэффициент **×2**, **2 попытки**, ставка **не меньше 1**, шаг **0,01**.
- Число WIN для дневной цели вычисляется автоматически из баланса и запланированной дневной прибыли. Показаны три модели: успех с первой попытки, успех на последней ступени, восстановление после одной полностью проигранной серии. Это **сценарии, не прогнозы**.
- Удалены поля «Желаемых WIN за день» и «Снижать ставку при ×2 баланса». Настраиваемые границы автоматической доли входа (0,25–1%) доступны в дополнительных параметрах.
- Кнопка **Свернуть/Развернуть** в заголовке калькулятора. Состояние сохраняется в Zustand по каждой цели отдельно. В свернутом состоянии видна короткая строка с расчётом.
- Ручной ввод ставки и каждой ступени сохранён; приложение предупреждает о риске, но не маскирует превышения лимита.

### Числовой пример

При балансе **5110**, первоначальном депозите **100**, четырёх попытках, выплате **92%**, множителе **2** и лимите **5%**: первая ставка **12,78**, дальнейшая цепочка `25,56 / 51,12 / 102,24`; суммарный проигрыш **191,70** (около **3,75%** баланса). При дневной цели **60,55** потребуется **6 побед с первой попытки**, если не будет проигрышей. При победе лишь на четвёртом шаге прибыль с одной успешной серии значительно меньше; повторные проигрыши могут превысить дневной лимит.

## Запуск и проверка

```bash
npm install
npm run test
npm run build
npm run dev
```

Для Vercel: Framework Vite, Build `npm run build`, Output `dist`, Root — каталог с `package.json`. Существующий сайт обновляется коммитом в `main`.

## Сохранность и миграция

- Ключ Zustand persist остаётся `yieldpilot-v2:<path>`. Существующие результаты, цели, календари и дневники сохраняются. Новые поля настроек восстанавливаются из дефолтов.
- **Уже заданный пользователем лимит риска 3% не меняется автоматически на 5%:** это может быть осознанное ограничение. Для новых целей и кнопки «Сбросить настройки» дефолт равен 5%.
- Данные можно переносить из резервной копии JSON старой совместимой версии. До публикации полезно сохранить локальную резервную копию данных.
- Состояние свёрнутости калькулятора хранится вместе с конфигурацией соответствующей цели.

## Безопасность и ограничения

- Калькулятор не торгует на бирже и не гарантирует достижение дневной цели. WIN/LOSS последовательности условны, и число сделок не является прогнозом.
- Лимит потери **одной серии** сравнивается с дневным бюджетом риска. Пока отдельные сделки не регистрируются, нельзя гарантировать соблюдение суммарного дневного лимита по нескольким сериям.
- При выплате ниже 100% схема ×2 при достаточно длинной серии может дать отрицательный итог даже после выигрыша.
- Зависимости npm в данной рабочей среде не были доступны по сети, поэтому полную Vite-сборку необходимо подтвердить в локальной системе или CI. Синтаксическая проверка TypeScript/TSX и математические сценарии выполнены.
